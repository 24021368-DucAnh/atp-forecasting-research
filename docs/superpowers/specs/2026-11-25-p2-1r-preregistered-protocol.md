## Temporal split (half-open, dates UTC-independent calendar event start)
Warmup: 2021. Fit starts 2022-01-01. For evaluation year Y, calibration starts July 1 of Y-1; fit events must mature (start +28 days <= calibration start). Calibration events start at/after that July 1 and mature by Jan 1 of Y. Evaluation starts Jan 1 Y and ends before Jan 1 Y+1. All event IDs entirely in one partition or gap within each fold. Gap rows not fit/calibrated; already-matured outcomes may update skill history. Fit preprocessing/calibration learned separately, model frozen throughout that year's evaluation, historical ratings update only when matured. Prior evaluation years may enter later rolling folds; not independent replications. 28 days is an estimated availability embargo, not proof of publication or match time. Any feature uses only matured outcomes with known event-start cutoff; same event and same-date state frozen. No within-event row order assumption. Minimum support in JSON fixed in advance; fail if inadequate rather than move boundaries. Report fit/cal/gap/eval counts and event support, calendar vs source season.

## Features / model
Stable source match key (tourney_id, match_num) required; trimmed exact IDs, lexical A/B orientation independent of outcome; preserve metadata separately from allowlisted numeric features. Pre-event Elo and surface experience, 90/365-day matured history, smoothed H2H, cold-start counts/support and surface only. No current rank/points without timestamped independent availability evidence; no current round, score, match statistics, duration, odds, player ID/name or schedule features. Rate prior Beta(1,1); no-history rating 1500, rate 0.5, counts zero, keep all eligible matches. Window by historical event start, only matured results; batch aggregate without ordering within date. No imputation from later data. Feature orientation test swaps A/B and negates signed features only. Fit-only mirrored augmentation; evaluation exactly one record per original key. Symmetrize output predictions using both orientations; clip for log loss.

Fixed comparators: coinflip, original Global Elo, original additive Surface Elo. Convex surface blend 0.35*n/(n+20), experience-decay K and mean per-player matured-date residual global update are three distinct one-change ablations, not alterations to frozen baseline. Rank baseline blocked. Logistic regression C=1 fit-only scaling and fixed XGB (parameters in JSON) are development candidates, no hyperparameter sweep. Calibration separate frozen-model Platt fit, mirrored calibration rows and symmetrized output; isotonic secondary sensitivity, never select by evaluation results. Calibration diagnostics fit evaluation logits for slope/intercept only, never fed back. No neural model. Explicit research-only fitting capability in P2.3 must be distinct from existing eligibility/trust flags; do not modify production policy.

## Evaluation
Full matched cohort, coverage denominator every eligible evaluation key, no dropping cold-start or missing predictions; missing predictions fail primary comparison. Primary LL, secondary Brier, fixed 10-bin ECE, reliability counts, slope/intercept, binned Brier decomposition with residual, fold and overall coverage. Report raw and calibrated predictions separately; use global Elo as common comparator, 2000 paired event-cluster percentile resamples stratified by year, seed 29; descriptive fixed predictions no refitting, repeated players induce dependence. Report all comparisons including negatives, no significance fishing or champion promotion. Feature ablations logistic Elo-only, Elo+history, full (surface context); fixed full XGB, compare same keys. Skill scorer includes ATP250 and does not require market probabilities.
