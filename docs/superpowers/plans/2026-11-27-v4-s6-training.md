## Interface decisions / pre-flight

- Add exact schema v5 (three append-only sidecars: training_protocols,
  candidate_artifacts, model_lifecycle_events), not modify v4 DDL.
  Existing v1→v4 entry points remain version-specific; verify/backup,
  S2 typed writes, S3 parser, S4/S5 read paths recognize exact v5.
  v5 migration atomic and idempotent. Old receipts are not rewritten.
- TrainingProtocol registers synthetic IDs, normalized registered_at,
  exclusive event-day fit/cal windows, training cutoff, preregistered
  future cohort ID and evaluation window, explicit minima (>=2) for
  fit/cal/matched. Fit and calibration disjoint, both canonical classes
  required separately before mirroring. Fixed seed 29, C=1, lbfgs,
  max_iter=2000, feature version/order, 28-day maturity, no tuning.
  Fit events and available/assessed labels mature before calibration
  begins; calibration events mature by training cutoff. Evaluate using
  latest result as of cutoff, no stale unavailable revision; exclude
  labels outside their split's knowledge deadline. Select all eligible
  baseline S5 commitments in windows, one per match, reject conflicting
  event dates or event split overlap; no caller feature/label input.
  Store exact feature/commitment/result/assessment IDs/digests and
  normalized clocks, values, labels, excluded counts and split digest.
  Fit/cal minimum checks after selection; insufficient support fails,
  not dates expanded. Future corrections after cutoff do not refit frozen
  candidate. Bound inventories and artifact size.
- Train on one verified read snapshot, fit outside transaction, then
  reselect and compare immutable dataset/protocol under BEGIN IMMEDIATE.
  Replayed registered protocol returns exact frozen candidate (no refit);
  new candidate created strictly after cutoff and no later than registered
  future evaluation start. S5 target selection retains strict prestart.
- Fit logistic on original+mirrored fit rows, StandardScaler on those
  rows only; mirror first 10 signed features, keep remaining 8. Calibrate
  fixed symmetric probabilities using explicit disjoint cal logits,
  mirrored labels and Platt logistic (V3 pattern). Frozen plain JSON
  coefficients/scaler/calibration, finite validated shape/order, stable
  clipped sigmoid, symmetric probability. Store code/dependency/config,
  protocol and dataset hashes and full lineage. Determinism verified
  within runtime/tolerance, not claim byte identity across OS versions.
- File artifact directory must be explicitly supplied existing absolute
  model_artifacts directory (ignored); reject traversal, symlink/reparse
  point or special files. Name from hash-derived synthetic model ID,
  bounded UTF-8 canonical JSON, no pickle. Stage exclusive temporary
  file then verified no-clobber hard-link. Store exact artifact JSON and
  model_version+registry in same DB txn; prepublished orphan on failure
  is safe (never auto-delete or overwrite; exact-byte retry may reuse).
  File is required for new candidate inference, verify against DB hash
  in same snapshot. DB receipt provides frozen historical verification
  without mutable filesystem dependency. Backup DB and artifacts
  separately; restored DB with missing/corrupt file denies new inference.
- Preserve baseline default, math/digests/legacy S5 receipt verification.
  Explicit registered model_id + model_dir for candidate inference/commit;
  model frozen before target, no consumed match/event as future target.
  Separate preview version for candidate; old commitments retain exact
  probability and evidence. Candidate comparison uses registered future
  cohort with same baseline/candidate, future window, no consumed
  match/event; exact matched fixture/result/outcome plus same cutoff
  and feature digest. Report coverage and exclusions, LL primary and
  other metrics, min matched support and descriptive-only uncertainty.
  No ranking or automatic replacement. Compare interim but approval
  requires window closed and min matched support. Do not reuse fit/cal
  outcomes for subsequent evaluation.
- Synthetic promotion events only: explicit typed approval for exact
  from/to model/config/artifact/evidence digest and clock, expected
  active model, append immutable event with sequence/previous digest,
  monotonic clocks, exact replay. Initial active baseline. Rollback
  selects previous active model of last promotion with explicit approval
  and evidence event digest, never updates old forecasts. No real
  production activation or inferred owner authorization; approval
  inputs are local synthetic simulation, not authentication. Existing
  baseline call stays baseline even after promotion; callers explicitly
  select active_model_id for future commitments. No background tasks.
- Weekly/200 eligible NEW matches readiness: count distinct matured
  baseline S5 matches newly eligible between previous check and as_of,
  no correction double-count, elapsed >=7 days and count >=200 only
  descriptive manual trigger, not statistical power. No implicit train.
