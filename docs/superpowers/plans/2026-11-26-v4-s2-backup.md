## Contract
backup_database(source: Path, destination: Path) -> Path;
restore_database(backup: Path, destination: Path) -> Path.
Use SQLite online backup API on separate read-only source connection;
do not copy the raw main file or checkpoint/modify the source. Include
committed WAL content, exclude uncommitted writes; concurrent committed
changes may be included according to SQLite snapshot semantics. Not a
continuous replication service. Source may require existing/readable WAL
and SHM sidecars; no immutable URI shortcut for a live database.
Destination parent must exist and be trusted, local filesystem; reject
existing destination (including symlink), same-file alias and destination
-wal/-shm/-journal sidecars. Stage with exclusive random temporary name
in same parent. Close all handles before publication, set staged copy to
DELETE journal mode, verify exact schema v3 and marker, foreign_key_check
and integrity_check on staged database. No unsupported-version repair.
Publish only verified closed single file via same-directory hard link
(no-clobber atomic creation) then unlink temporary name; fail closed if
filesystem lacks hard links. Intended Windows NTFS/local Linux scope,
not network/FAT filesystems. No overwrite fallback. Recheck destination
sidecars before publication; concurrent external mutation of target
directory is outside trusted single-user contract. Clean only owned
temporary files and sidecars on exceptions; preserve source and any
existing destination. No absolute power-loss durability guarantee.
Restore copies and verifies again into a new path, does not replace
a running DB. To reopen restored copy for writes use open_writer().
Failure errors: FileExistsError for occupied destination or sidecars;
ValueError for unsupported/damaged schema; SQLite error for corrupt input;
missing source must not create any files. Return caller Path.
Read-only source, caller-owned writer transactions must not be committed.
No promise of external authentication or protection from a malicious
local administrator. Local logical consistency only.
